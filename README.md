# Cura Clinic - Mini Website Landing Page

Website profil dan landing page klinik dokter umum **Cura Clinic** dengan desain modern responsif (mobile-first), katalog layanan, estimasi biaya, FAQ interaktif, dan integrasi pemesanan WhatsApp langsung.

---

## 🚀 Cara Melihat Preview

Server preview sudah aktif dan dapat dibuka langsung melalui browser:

👉 **[http://localhost:5174/](http://localhost:5174/)** *(atau port yang sedang berjalan)*

---

### Cara Menjalankan Kapan Saja:

#### Opsi 1: Klik Ganda File (Paling Mudah)
Klik dua kali file **`start-preview.bat`** yang ada di folder ini. Browser akan otomatis terbuka dan menampilkan website.

#### Opsi 2: Lewat Terminal / Command Prompt
```bash
npm run dev
```

---

## 🛠️ Perintah Lainnya

- **Membangun versi produksi:**
  ```bash
  npm run build
  ```
  File statis siap deploy akan dihasilkan di folder `dist/`.

- **Melihat preview versi build produksi:**
  ```bash
  npm run preview
  ```
